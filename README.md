# 晴空跃行

一只候鸟穿越天空群岛的原创休闲飞行游戏。点击天空或按空格拍翼，在四种自然景色中穿过遗迹、收集星光，收藏属于旅途的羽翼。

![晴空跃行游戏画面](docs/images/game-preview.png)

## 立即游玩

启动开发服务后，访问 **http://localhost:5178/**。如果已能访问，不必重复启动。

手机、平板请竖屏游玩。在同一局域网中，可使用运行电脑的局域网 IP 和端口 `5178` 访问。手机上的 `localhost` 指向手机自身，不能用来访问电脑。需要设备处于可互访的网络，并由现有防火墙规则允许访问；项目不会自动改变系统设置。

## 启动、测试与构建

本项目在 Windows、Node.js 22.18.0、npm 10.9.3 下完成构建。推荐 Node.js 22.12 及以上版本。

```powershell
git clone https://github.com/Mesting42/qingkong-yuexing.git
cd qingkong-yuexing
npm ci
npm run dev
```

```powershell
npm test
npm run build
npm run preview
```

- `dev`：开发预览，固定端口 **5178**，端口占用时直接报错，不会停止其他服务。
- `test`：运行输入、物理、路线、碰撞、奖励、存档、状态与长时间模拟测试。
- `build`：TypeScript 检查后生成 `dist/`，所有图片和字体随构建复制。
- `preview`：预览构建结果，固定端口 **4178**。

不能双击 `index.html` 以 `file://` 方式运行源码，应使用以上 HTTP 预览或静态托管。

## 操作

| 操作 | 电脑 | 手机与平板 |
| --- | --- | --- |
| 拍翼 | 点击游戏区域 / 空格 | 轻点游戏区域 |
| 磁铁 | E / 点击磁铁按钮 | 点击磁铁按钮 |
| 暂停 | Esc、P / 暂停按钮 | 点击暂停按钮 |
| 继续 | 点击继续飞行 | 点击继续飞行 |

点击「启程飞行」进入准备状态，再点击天空或按空格，才会进行第一次拍翼。长按不连续拍翼。切后台、失焦、旋转或明显改变窗口尺寸会暂停；恢复飞行有 1.5 秒准备时间。

竖向逻辑战场固定为 **432×768**，桌面横屏和设备横屏也保留这块竖向战场，不增加横向预警距离。触屏设备以竖屏为主要体验。

## 玩法与完整内容

- **经典飞行**：从宽松间隙开始，在 6、16、30、50、80、120 分进入新阶段，16 分后挑战加强，最终速度上限 250、经典间隙 160，速度和难度有上限。
- **混乱气流**：相同拍翼物理，增加波浪节奏与缓慢移动间隙，独立保存最佳成绩。
- **精准穿越**：在越过计分平面时，鸟的中心距离实时门中心不超过 30 逻辑像素即精准。连续每三次奖励一颗星星。普通通过或护盾触发会中断连击。
- **星星**：实际拾取增加本局收益和磁铁进度，不再给护盾充能；精准奖励及任务奖励只增加收益/余额。
- **护盾**：独立的青色护盾拾取物，约每 20～30 组障碍出现一次，接触后才获得保护。最多一层，重复拾取不能叠加或存备用；持盾时不再生成，消耗后重新等待 20～30 组。磁铁不吸引护盾。吸收障碍、地面或上边界事故后安全复位，提供 2.2 秒保护。保护期间可能接触的障碍整组淡化且无伤害，不能获得精准连击。
- **磁铁**：单局拾取十五颗场景星星后解锁，主动使用一次，持续八秒，只吸引附近星星。暂停冻结时间。
- **四主题**：晨光海湾、林间浮岛、雪峰云海、暖色落日，拥有独立远景插画、环境动态和障碍材质。
- **九外观**：初晴默认可用，另外八种用星星解锁；羽冠、尾羽、围巾、缎带、帽子、护目镜等提供形态差异，物理与碰撞公平一致。
- **十六任务**：即时进度检测、完成通知、领取奖励、已领取标记与本地持久化。
- **完整界面**：主页、模式选择、HUD、准备、暂停、失败结算、收藏、任务、设置、操作说明。
- **声音**：原创五声音阶背景音乐与拍翼、通过、精准、连击、拾星、道具、受击、纪录、任务和菜单音效。

没有护盾时，撞上障碍、触到地面或飞出上边界会结束本局。失败反馈约 0.4 秒，之后可立即重试。

## 保存与静态部署

无需账号、后端、运行时 AI 或远程资源。所有正式素材均在 `public/`，音频在浏览器内合成。存档键为 `clearwing.journey.save.v1`，与其他游戏隔离。

本局收益在失败结算或「结束本局并返回」时一次性保存；任务奖励到任务页领取。设置、装备与主题选择立即保存。损坏或未知版本存档会安全回退；存储不可用时仍可玩，但无法保证关闭后的进度。

存档按浏览器源隔离：`localhost`、`127.0.0.1`、不同端口与正式域名的进度各自独立。切换预览地址不会自动迁移进度，原地址中的已存进度仍在。

部署 Cloudflare Pages 等静态平台：构建命令 `npm run build`，输出目录 `dist`，使用 Node.js 22。也可构建后直接上传 `dist/` 中的文件。无需环境变量或服务器函数。默认部署在站点根路径。
