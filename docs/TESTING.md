## 浏览器真实输入实玩

浏览器验证通过实际菜单点击、鼠标指针与键盘事件进行。开发版只读 DOM 遥测用来观察鸟、障碍和道具状态；没有通过它改分、修改角色位置、强制发奖或调用结算。

| 验证 | 观察到的结果 |
| --- | --- |
| 经典实际飞行 | 先达到 13 分、38 颗场景星星、40 颗收益星星、最高精准 4 连；护盾和磁铁实际触发 |
| 保护后继续飞行 | 故意停止拍翼触发一次护盾保护，恢复时仍为 `flying`，保护剩余约 2.15 秒，附近障碍无害；随后继续飞到 18 分 |
| 混乱实际飞行 | 10 分、29 颗场景星星、32 颗收益星星、10 次精准连击；移动障碍幅度非零，磁铁已使用并计时 |
| 长按空格 | 持续约 800ms 后，`flapCount` 仍为 1 |

| 生产构建闭环 | 静态预览实际起飞，停止输入后自然落地，约 0.4 秒反馈后显示结算、再飞一次、返回主页 |

## 未执行与已知限制

- 没有实体 iPhone、Android 手机或平板的硬件实测，不能把浏览器尺寸检查称为真实触屏实测。触屏事件适配逻辑经过测试，实际设备延迟、刘海安全区域和工具栏伸缩仍待设备验收。
- 没有独立 Firefox / Safari 的兼容性运行，也没有对不支持全屏的真实 Safari 进行验证；代码提供功能检测和失败提示。
- Web Audio 逻辑与触发路径已接通，但没有独立听音设备的主观音质验收。
- 十二分钟测试证明规则推进与对象数量有界，不等于长期浏览器堆内存曲线或帧率达标证明。
- 路线筛查与大量模拟未发现明显无解组合，但不是对无限随机序列的数学证明。
- 存档按浏览器源隔离；`localhost`、`127.0.0.1`、不同端口或正式域名拥有不同进度。没有云同步、多标签合并、进行中的一局自动续玩或 PWA 离线安装。
